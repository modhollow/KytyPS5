# Release notes

Versioned release notes and checksums are published on the [Releases page](https://github.com/modhollow/KytyPS5/releases). Each release must identify its exact source revision, package contents, source credits and verified game progress, including remaining compatibility and performance limits.

The [testing guide](https://github.com/modhollow/KytyPS5/wiki/Testing-and-Known-Issues) distinguishes public versions from historical results obtained with other builds.
